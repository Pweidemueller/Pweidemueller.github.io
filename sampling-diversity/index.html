How does sampling shape what we see of an outbreak?

Birth-death-sampling simulations run with remaster (a BEAST2 package), comparing a low- and a high-sampling regime two different ways: first by simply changing the sampling rate (which also changes how far the outbreak gets), then by changing only the sampling proportion while holding the epidemic's reproduction number and removal rate fixed (so the underlying outbreak is unchanged and only who gets sampled differs).

The true transmission tree

remaster simulates the full tree of everyone ever infected, not just who gets sampled. This is a small illustrative simulation (same birth/death rates, a short time window) so every event is visible — a general introduction to birth-death models before the two comparisons below. Drag the slider from root to tips — each birth, death, or sampling event lights up as the simulation clock passes it, and the reconstructed sampled tree below builds up in step. The full outbreak is exactly the same either way — toggle the sampling proportion to see how many, and which, of the same 32 infections end up as observed sequences.
